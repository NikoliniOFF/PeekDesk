## 👀 PeekDesk для Windows 1.3.0

**Скачать:** `PeekDesk-1.3.0-win64.zip` ниже (или постоянная ссылка `PeekDesk-win64.zip`). Если PeekDesk уже установлен, он сам предложит обновиться (или обновится сам в режиме «Автоматически»).

### Что нового
- 🖥️ **Просмотр во весь экран — для любого файла.** Видео, фото, PDF, Word, Excel, код, папки, архивы — нажмите кнопку с двумя стрелками в шапке окна, и вместо окошка файл плавно развернётся на весь монитор, вместе с панелью задач.
- ⌨️ **Клавиши и двойной щелчок.** <kbd>F</kbd>, <kbd>F11</kbd> или <kbd>Alt</kbd>+<kbd>Enter</kbd> — во весь экран и обратно. Двойной щелчок по видео или фото — тоже. <kbd>F11</kbd> работает даже прямо из Проводника, пока открыт просмотр.
- ▶️ **Без перезагрузки.** Это тот же просмотр, просто большой: видео продолжает играть с того же места, PDF остаётся на той же странице, стрелки листают выделенные файлы и лента миниатюр работает, не выходя из полноэкранного режима.
- 🌑 **Ничего лишнего.** Фото и видео — на чёрном фоне и вписаны в экран, документы — на обычном фоне темы. Через 2 секунды без движения мыши шапка, панель плеера и курсор прячутся; шевельнули мышью — вернулись.
- ⎋ **Esc — обратно в окно**, второй <kbd>Esc</kbd> закрывает просмотр. Пробел, как и раньше, закрывает сразу.

### Подробнее
- Включается и выключается в «Настройки → Удобство → Полноэкранный режим» (по умолчанию включено). Пункт «Во весь экран» есть и в меню «⋯».
- Разворачивается на тот монитор, где сейчас окно, с учётом масштаба этого монитора.
- Лёгкость не пострадала: в окне и в трее ничего нового не работает, таймеры полноэкранного режима живут, только пока он включён. Открытие файлов — по-прежнему без прыжков и чёрных кадров.

### Если Windows предупреждает
SmartScreen может показать «Система Windows защитила ваш компьютер» — нажмите «Подробнее» → «Выполнить в любом случае».

**Требования:** Windows 10 или 11, 64-бит.
