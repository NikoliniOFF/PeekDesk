## 👀 PeekDesk для Windows 1.0.0

**Скачать:** `PeekDesk-1.0.0-win64.zip` ниже (или постоянная ссылка `PeekDesk-win64.zip`). Распакуйте и запустите `PeekDesk.exe` — значок появится в трее.

### Что нового
- Первый выпуск: предпросмотр по пробелу в Проводнике и на рабочем столе
- Картинки и GIF, Excel, CSV, Word, PDF, текст и код, аудио и видео, папки и ZIP
- Поиск по Ctrl+F и копирование выделенного текста или ячеек
- Масштаб и поворот картинок, скорость и перемотка видео
- Меню «…»: показать в папке, копировать путь и имя
- Светлая и тёмная тема, размер окна запоминается для каждого типа файлов

### Подробнее
- Окно появляется за доли секунды; большие таблицы и логи дочитываются в фоне.
- В трее PeekDesk ничего не опрашивает и почти не тратит память; PDF и видео загружаются только при первом открытии.
- Каждый формат и каждая функция включается отдельно в настройках.
- `PeekDesk.exe --preview <файл>` — открыть файл напрямую.

### Если Windows предупреждает
SmartScreen может показать «Система Windows защитила ваш компьютер» — нажмите «Подробнее» → «Выполнить в любом случае».

**Требования:** Windows 10 или 11, 64-бит.
