## 👀 PeekDesk для Windows 1.2.2

**Скачать:** `PeekDesk-1.2.2-win64.zip` ниже (или постоянная ссылка `PeekDesk-win64.zip`). Если PeekDesk уже установлен, он сам предложит обновиться (или обновится сам в режиме «Автоматически»).

### Что нового
- 🎬 **Видео открывается без «прыжков» и чёрного экрана.** Раньше сначала мелькала маленькая миниатюрка, потом окно на полсекунды становилось чёрным и только после этого шло видео. Теперь с первого же кадра виден первый кадр ролика — ровно там, где он будет играть, — и воспроизведение просто начинается.
- 📐 **Окно сразу нужной формы.** Вертикальные ролики с телефона открываются вертикальным окном, широкие — широким: размер кадра PeekDesk узнаёт ещё до показа окна.
- 🎵 **Музыка — сразу с обложкой.** Обложка альбома, название и исполнитель видны с первого кадра, в аккуратном квадратном окне. Обложку PeekDesk теперь достаёт из самого файла, даже если Проводник показывает вместо неё значок.
- 📄 **PDF — сразу со страницей.** Первая страница рисуется ещё до показа окна, поэтому серого пустого листа больше нет.
- 🖼️ **Большие фото — без пустого окна.** Пока JPEG на десятки мегапикселей дочитывается, видна её уменьшенная копия, а потом она плавно сменяется полной.
- ✨ Плавное появление окна начинается, когда в нём уже есть картинка, а при листании файлов прежний остаётся на экране, пока следующий не готов (не дольше доли секунды) — без мигания.

### Подробнее
- Окно ждёт содержимое не дольше 0,12 с — если файл тяжёлый, окно появится вовремя и дорисуется, как раньше.
- Лёгкость не пострадала: ничего нового не работает в трее, память и процессор в простое — как в 1.2.1.

### Если Windows предупреждает
SmartScreen может показать «Система Windows защитила ваш компьютер» — нажмите «Подробнее» → «Выполнить в любом случае».

**Требования:** Windows 10 или 11, 64-бит.
