## 👀 PeekDesk для Windows 1.4.2

**Скачать:** `PeekDesk-1.4.2-win64.zip` ниже (или постоянная ссылка `PeekDesk-win64.zip`). Если PeekDesk уже установлен, он сам предложит обновиться (или обновится сам в режиме «Автоматически»).

### Что нового
- 🔄 **Проверка обновлений больше не упирается в лимит GitHub.** Раньше, если на компьютере стояло несколько программ, GitHub мог ответить «403», и проверка не срабатывала. Теперь PeekDesk узнаёт новую версию другим способом, без этого лимита. А если GitHub всё же временно недоступен, PeekDesk не показывает ошибку, а тихо проверит позже.
- 🧩 **Все программы Nikolini в окне «О программе».** HubDesk первым, затем WinterDesk, SnapDesk, DockDesk, SpotDesk и IslandDesk, с новыми значками. Щелчок по карточке открывает сайт программы. Список обновляется сам, когда вы открываете настройки, а без интернета показывается встроенный.

### Подробнее
- Скорость открытия файлов и память не изменились. Список программ загружается только при открытии настроек, в фоне PeekDesk его не трогает.
- Каждое обновление по-прежнему проверяется по контрольной сумме SHA-256.

### Если Windows предупреждает
SmartScreen может показать «Система Windows защитила ваш компьютер» — нажмите «Подробнее» → «Выполнить в любом случае».

**Требования:** Windows 10 или 11, 64-бит.
